# Casa del Sol Restaurant

![Casa del Sol homepage](casa_ss.jpeg)

**Casa del Sol Restaurant** — an online ordering app for a restaurant, with pickup, delivery, and live order tracking. Customers browse the menu and order online, while managers and drivers coordinate deliveries in real time.

### Features
- Menu browsing and online ordering
- Pickup and delivery options
- Live order notifications
- Manager dashboard with real-time incoming orders and driver assignment
- Driver dashboard showing assigned deliveries live

*Built for a client — source code kept private.*
